# Local SEO Trust Playbook

Use this as the operating checklist for adding real trust proof to ACE Properties KC without weakening compliance or credibility.

## Google Business Profile

- Confirm the public business name matches the website: `ACE Properties KC`.
- Confirm the primary phone matches the site: `816-728-7548`.
- Confirm the website URL is `https://acepropertieskc.com/`.
- Use service-area business settings if the business does not receive sellers at a public office.
- Add services for core seller intents:
  - Cash home buyer
  - Sell house as-is
  - Inherited property sale
  - Probate property sale
  - Foreclosure or behind-on-payments sale
  - Tenant-occupied property sale
  - Vacant house sale
- Add service areas that match real operating coverage: Kansas City, Independence, Lee's Summit, Overland Park, Olathe, Shawnee, Lenexa, and ZIP 64131.
- Add real photos only:
  - team photo
  - branded vehicle/signage if available
  - local exterior/property project photos with permission
  - closing/process photos only when privacy is protected

## Reviews

- Ask only real customers, sellers, partners, or people who directly experienced the business.
- Do not offer payment, gifts, discounts, or pressure for reviews.
- Ask shortly after a positive outcome or helpful consultation.
- Respond to every review calmly and locally.
- Do not add Review schema to the site until reviews are visible on-page and attributable.

Suggested review ask:

```text
Thanks again for trusting ACE Properties KC. If the process was helpful, would you be willing to leave a quick Google review? It helps other Kansas City homeowners understand what it is like to work with us.
```

## Website Trust Assets

Collect these before adding them to the site:

- Google Business Profile URL
- Google review link
- 3-5 real seller testimonials with permission
- reviewer first name and city, if approved
- team photo
- short founder/team bio
- real local project examples with no private seller details
- social/profile URLs for `sameAs` schema

## Where To Add Assets

- Add real team bio and photo to `/about/`.
- Add selected testimonials to `/about/`, `/get-offer/`, and homepage only after permission.
- Add project examples to relevant solution pages, such as repairs, inherited, vacant, and tenant-occupied.
- Add `sameAs` links in `src/lib/siteConfig.ts` and `src/lib/seo.ts` only after profiles are confirmed.

## Search Console Inputs

Monthly export:

- Performance by query
- Performance by page
- Indexing report
- 404/not found URLs
- Pages with impressions but low CTR
- Pages ranking positions 8-30

Use the export to decide:

- which titles and descriptions need rewrites
- which pages need more copy or FAQs
- which new location pages are justified
- which old URLs need redirects
- which pages get traffic but no leads
